# trust_game

An updated trust game with uncertain marginal returns and a 2-by-2 partner-cue treatment:
picture/no picture crossed with written description/no written description.

The participant flow has three parts:

0. General instructions about the show-up payment and the option to leave.
1. Self-demographic survey before the game in written-description sessions, or trust-game instructions, quiz, and decisions in no-written-description sessions.
2. Trust-game instructions, quiz, and decisions in written-description sessions, or self-demographic survey after the game in no-written-description sessions.
3. Partner-demographic guesses after the decision task in picture-treatment sessions only.
